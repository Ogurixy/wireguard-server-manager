# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities, SSH keys, WireGuard private
keys, passwords, full client configurations, or real server addresses in a
public issue.

Use GitHub's private vulnerability reporting feature on the repository's
**Security** page. Include the affected version, impact, reproduction steps,
and a minimal redacted example.

If a secret was accidentally committed or posted publicly, removing the text
is not sufficient. Revoke or rotate the exposed credential immediately.

## Supported versions

Security fixes are provided for the latest published release.
